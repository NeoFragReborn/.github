# Obtenir de l'aide

- **Installer, configurer, utiliser le CMS** : la documentation — [guides](https://github.com/NeoFragReborn/neofrag/tree/main/docs/guide),
  publiés aussi dans le wiki de chaque site qui a le module Wiki —, puis les
  [Discussions](https://github.com/NeoFragReborn/neofrag/discussions) du dépôt `neofrag` pour une
  question qu'elle ne règle pas.
- **Un bug** : une issue dans le dépôt concerné — [neofrag](https://github.com/NeoFragReborn/neofrag/issues)
  pour le CMS, [extensions](https://github.com/NeoFragReborn/extensions/issues) pour un addon à la
  carte, [bot-discord](https://github.com/NeoFragReborn/bot-discord/issues) pour le bot —, avec la
  version, ce qui se passe, et ce qui était attendu.
- **Une faille de sécurité** : jamais d'issue publique — la [politique de sécurité](SECURITY.md).

Le projet est écrit et documenté en français.
