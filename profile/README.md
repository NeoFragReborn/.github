Forum, actualités, événements, membres, dons, wiki, galerie, modération, messagerie — et, pour les
équipes de jeu, équipes, matchs, recrutement et palmarès. NeoFrag Reborn s'installe sur un hébergement
mutualisé, sans Docker ni shell.

### 📦 Les dépôts

| Dépôt | |
|---|---|
| 🧱 [neofrag](https://github.com/NeoFragReborn/neofrag) | le CMS : son cœur, les addons de ses profils d'installation, la documentation, les tests |
| 🧩 [extensions](https://github.com/NeoFragReborn/extensions) | les addons à la carte, proposés par le marketplace |
| 🤖 [bot-discord](https://github.com/NeoFragReborn/bot-discord) | le bot qui relie un site et son serveur Discord |

### 🚀 Pour commencer

- 🎮 **Essayer** — la [démonstration](https://demo.neofrag-reborn.xyz), sans rien installer ;
- 📥 **Installer** — le paquet de la [dernière version](https://github.com/NeoFragReborn/neofrag/releases/latest),
  à téléverser chez l'hébergeur, puis l'assistant d'installation ;
- 📖 **Apprendre** — les [guides](https://github.com/NeoFragReborn/neofrag/tree/main/docs/guide), publiés
  aussi dans le [wiki du site](https://neofrag-reborn.xyz/wiki) ;
- 💬 **Échanger** — le [serveur Discord](https://discord.gg/UmBRbwxtch) et les
  [Discussions](https://github.com/NeoFragReborn/neofrag/discussions).

### 🌍 In English

**NeoFrag Reborn** is a free PHP CMS (LGPL-3.0-or-later) for communities, from gaming teams to
associations: forum, news, events, members, donations, wiki, gallery, moderation and messaging, plus
teams, matches and recruitment for gaming teams. It installs on ordinary shared hosting, with no Docker
or shell. Try the [demo](https://demo.neofrag-reborn.xyz), grab the
[latest release](https://github.com/NeoFragReborn/neofrag/releases/latest) or join us on
[Discord](https://discord.gg/UmBRbwxtch). The project is written and documented in French.
