# NeoFrag Reborn

Le CMS PHP libre des communautés, du gaming aux associations : forum, actualités, événements, membres,
dons, wiki, galerie, modération, messagerie — et, pour les équipes de jeu, équipes, matchs,
recrutement et palmarès. Il s'installe sur un hébergement mutualisé, sans Docker ni shell.

| Dépôt | |
|---|---|
| [neofrag](https://github.com/NeoFragReborn/neofrag) | le CMS : son cœur, les addons de ses profils d'installation, la documentation, les tests |
| [extensions](https://github.com/NeoFragReborn/extensions) | les addons à la carte, proposés par le marketplace |
| [bot-discord](https://github.com/NeoFragReborn/bot-discord) | le bot qui relie un site et son serveur Discord |

**Site :** [neofrag-reborn.xyz](https://neofrag-reborn.xyz) · **Démonstration :**
[demo.neofrag-reborn.xyz](https://demo.neofrag-reborn.xyz) · **Installer :** le paquet de la
